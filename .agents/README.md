# Igniter-Lang Agent Workspace

Status: split-era agent index
Updated: 2026-06-06

`.agents` contains operating context, roles, cards, discussions, proposals, and
tracks used by Igniter-Lang agents. It is not the language documentation index;
use [`../docs/README.md`](../docs/README.md) for reader-facing language docs.

## Placement Rule

- Put agent cards, handoff context, discussions, proposals, and route evidence
  here.
- Put language specs, user-facing docs, package notes, and conceptual docs in
  `docs/`.
- Put executable package code in `lib/`, `bin/`, `source/`, `fixtures/`,
  `tests/`, `examples/`, or selected `experiments/`.

## Boundary

Agent artifacts coordinate work and preserve evidence. They do not create
stable grammar, public API, runtime support, Reference Runtime status,
production readiness, release execution, public performance claims,
certification, portability guarantees, or cross-repository authority.
